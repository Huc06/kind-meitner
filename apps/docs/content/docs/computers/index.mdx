A bot can work without a computer, or use the computer running kind-meitner.

| Backend | Isolation | Best for |
|---|---|---|
| This computer | None | Working with local apps and files you explicitly approve |
| Off | — | Chat, files, and connected apps without screen control |

Computer use is local only. Cloud computers, containerized local VMs, and self-hosted VPS desktops are not available.

## This computer

Choose **This computer** on a bot to let a supported engine use the host through the bundled CUA driver. It stays off until you turn it on. Risky actions still go through the bot's approval level.

<Callout type="warn" title="Preview is not permission">
  Starting a screen preview does not grant the bot control. Local input requires a separate opt-in and remains subject to the computer-use safety boundary.
</Callout>
