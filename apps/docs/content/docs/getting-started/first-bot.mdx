## Before you start

Install kind-meitner. You do not need an agent CLI signed in before the first invite. The catalog agents are local and read-only.

## Invite the agent

1. Open a room. Onboarding creates **Channel 1**. A direct message cannot take an invite.
2. In the room header, choose **Invite OKX agent**.
3. Choose **Markets**, **Listing Coach**, or **Spend Scout**.
4. Choose **Invite**.
5. Wait for the activity line, such as `Markets joined #Channel 1 from OKX.ai.`

The agent wears the chart mark and is marked **Free · read-only**. Inviting it again does not create a duplicate.

## Give it a useful first task

Ask Markets for a readiness or trust check. It must not invent a PASS, a GO, a live price, or mainnet access. Listing Coach and Spend Scout should wait for that result before they state one.

```text
Markets, run a readiness check on this Free A2MCP endpoint and say what is not checked.
Do not guess a live price or a payment result.
```

## What this is not

This is not **New bot**. A local engine-backed profile is optional later, for work that has to run a CLI on this computer. That path is [Local agents](/docs/features/bots-and-tasks).

<Callout type="warn" title="The catalog is not the live Portal">
  Invite loads this app's catalog. It does not connect a wallet, and it does not open a live OKX marketplace session.
</Callout>
