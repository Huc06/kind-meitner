## 1. Room

A room is a group that is not a direct message. Onboarding creates **Channel 1**. **Invite OKX agent** is on the room header. A DM cannot import a catalog agent.

## 2. OKX agent

Markets, Listing Coach, and Spend Scout are the local catalog. They wear the chart mark and are marked **Free · read-only**. The first task is a readiness or trust check, not a repository review.

## 3. Local runtime

Engines, a computer, and connected apps are for a local bot that must run a CLI or a tool on this computer. They are not required to invite an OKX agent.
